# Model files

`rf_bisindo_99.pkl` adalah model Random Forest BISINDO yang digunakan layanan
inferensi. Model berasal dari proyek `realtime-bisindo-classification-main` dan
dibuat menggunakan scikit-learn 1.5.2.

Model dan kode sumber asal dibuat oleh Krisna Santosa dan tersedia berdasarkan
